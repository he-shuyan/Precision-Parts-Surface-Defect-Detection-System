# 精密零件表面缺陷检测系统 1.0

面向精密零件表面质量检测的完整系统，支持**图片连续输入、缺陷识别分类、结果输出**。
主检测引擎为项目**自训练的 YOLOv8 深度学习模型**，并内置经典图像处理引擎作为兜底，
即使在没有深度学习环境时也能运行。

可识别三类常见缺陷：

| 缺陷类型 | 英文标签 | 说明 |
| --- | --- | --- |
| 划痕 | scratch | 零件表面的细长线状损伤 |
| 锈迹 | rust | 橙色/棕色的腐蚀区域 |
| 缺漆/斑点 | paint_loss | 亮度异常的大块区域 |

## 一、模型与性能

- 模型：YOLOv8n（COCO 预训练迁移学习），输入 640×640，3 类缺陷
- 数据：程序化合成数据集 1100 张（训练 935 / 验证 165），自动生成 YOLO 标注
- 硬件：NVIDIA GeForce RTX 5060 Laptop（8 GB），CUDA 12.8
- 验证集指标（第 100 轮）：

| 指标 | 数值 |
| --- | --- |
| 精确率 Precision | 97.66% |
| 召回率 Recall | 94.98% |
| mAP@50 | 97.99% |
| mAP@50-95 | 70.53% |

完整训练曲线、PR 曲线、F1 曲线、混淆矩阵见
`报告/模型训练与评估报告.html`（自包含网页，可直接打印为 PDF）。

## 二、快速开始

1. 双击运行 `启动系统.bat`（自动使用项目内置的 Python 环境）。
2. 浏览器自动打开 `http://127.0.0.1:8000`。
3. 点击“选择图片”或“选择文件夹”载入图片。
4. 点击“批量检测全部”，或在图片间切换时自动检测。
5. 查看标注结果，并导出标注图 / 检测报告。

手动启动：在项目目录执行 `python\python.exe app.py`（内置环境），
或 `python app.py`（已按 `requirements.txt` 安装依赖的普通 Python）。

## 四、系统架构

图片 → 本地服务 → 检测引擎（YOLOv8）→ 缺陷框/类别/置信度 → 网页标注 + 报告导出

检测引擎为可插拔设计：

- `YoloEngine`：加载 `models/defect_best.pt` 做深度学习推理；
- `ClassicalEngine`：经典图像处理，无依赖兜底；
- `get_engine()` 自动选择——模型存在且环境可用时使用 YOLOv8，否则回退经典算法。

## 五、重新训练（可选）

```bat
python\python.exe make_dataset.py    :: 生成合成数据集
python\python.exe train_model.py     :: 训练模型并导出 ONNX
python\python.exe make_report.py     :: 生成评估报告
```

## 六、功能说明

- **连续输入**：一次选择多张图片或整个文件夹，方向键 / 按钮连续切换。
- **缺陷识别分类**：识别划痕、锈迹、缺漆/斑点，标注位置与置信度。
- **结果输出**：导出当前图片标注图（PNG）；导出全部检测结果报告（HTML）。

## 七、注意事项

- 当前模型在**合成数据**上训练，适合成果演示与算法验证；用于真实产线前，
  建议采集真实缺陷样本微调（把真实图片按 YOLO 格式加入 `dataset/` 后重新训练）。
- 项目内置 Python 环境适用于 64 位 Windows；换机器可参照 `requirements.txt` 重新安装。
- 请勿将包含身份证号、手机号、邮箱等隐私信息的文件随意外传。
